# Project Brief: Somae

**Somae** is a Chrome extension (side panel) — an AI-powered marketing creative assistant. It helps founders, marketers, small businesses, and content creators generate high-quality, on-brand marketing visuals faster.

> Formerly codenamed "Huenxt" — rebranded to Somae (Private Beta 01).

## Core Requirements

- Single Chrome extension interface (side panel), not multiple pages/tabs.
- Brand setup: upload logo + brand name once, persisted and reused intelligently in every generation (logo preserved exactly, never redesigned).
- Creative workflow: content type → marketing goal → description (with AI Smart Prompt) → creative style → optional reference image → quality tier → generate.
- Structured internal creative system: user intent + goal + content type + style direction + reference + logo + quality are combined into an optimized generation request. Users never see prompt construction.
- Result screen: large preview, generation navigation, variants rail, new variants, remake/regenerate, conversational refinement, download, history, per-asset feedback.
- User authentication and licensing (license key validated against the Somae web backend).

## Product Principle

Somae is NOT a generic AI image generator. It is an AI-powered creative workflow layer for marketing — its value comes from simplifying the workflow, structuring creative intent, applying creative systems, saving brand context, and guiding users toward better outputs.
