# Project Brief: Somae

**Somae** is a browser extension that provides AI-powered image generation capabilities directly in the browser. It allows users to generate images based on textual prompts and configurations.

## Core Requirements

- Generate images from textual prompts.
- Provide configuration options for the image generation process (e.g., model selection, image dimensions, style).
- Allow users to view and manage generated images.
- Integrate with a browser as an extension.
- User authentication and licensing.
